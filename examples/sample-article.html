Claude Skills 是 Anthropic 在 2025 年底推出的開放式能力擴展架構、把專業領域知識打包成 Claude 可動態載入的模組。Anthropic 官方 GitHub Repo 提供 17 個 Skills——從 Office 文件（pptx xlsx docx pdf）到 Frontend Design、MCP Builder、Slack GIF Creator、Webapp Testing、Skill Creator 等橫跨 Creative、Development、Enterprise 三大領域。除了官方 Skills、社群創作的 Custom Skills 也爆炸成長。2025 年 12 月 Anthropic 把 Skills 規格開放成 Industry Standard、OpenAI Cursor Gemini CLI 也採用同樣格式、Skills 跨 AI 平台 Portable。這篇 Claude Skills 完整教學會拆解三層架構、SKILL.md 格式、Progressive Disclosure 機制、實戰場景、限制和最佳實踐。

Moksa 觀點：我顧問業每個客戶有獨特 Style——財報用某種 Layout、Pitch 用某種敘事公式、合約用某種條款結構。以前每次和 Claude 對話要重新解釋一遍。寫了 5 個 Custom Skills（一個客戶一個）丟進 Claude.ai 之後、Claude 自動偵測使用情境呼叫對的 Skill、產出立即符合該客戶風格。最甜的是 Skills 是 Open Standard、我同樣的 Skill 在 ChatGPT Codex 也能用、不會被 Vendor Lock In。對知識工作者這個架構是「個人專業知識的 AI 化」、把過去寫在 Notion 的 Best Practice 變成 AI 可執行的能力。

1. 什麼是 Claude Skills？三層架構概覽

Claude Skills 是組織化資料夾——含 SKILL.md 指令檔、輔助 Script、Reference 文件——讓 Claude 動態載入專業能力。傳統 LLM 對所有問題用同一套 General Knowledge 回答、Skills 讓 Claude 變成「專業 Agent」、面對 PowerPoint 任務用 PowerPoint Skill、面對你公司合約用你的 Custom Legal Skill。

它分三層架構。第一層 Pre-built Skills——Anthropic 維護的官方 17 個 Skills、所有用戶自動可用。第二層 Custom Skills——你或你公司寫的領域專業 Skills、上傳到 Claude.ai 或部署到 Claude Code skills 資料夾。第三層 Workspace Skills——Team Enterprise Admin 集中部署 Skills 給整個組織。

2. Claude Skills 和 ChatGPT GPTs 怎麼選？

選擇 Claude Skills 的關鍵理由是 Open Standard、不被 Vendor Lock In。寫一次跨多平台用。ChatGPT GPTs 的優勢是 GPT Store Discoverability。實務上專業助理用 Custom GPT、互動工具用 Skills、組合互補。

3. 如何啟用這個工具？

啟用流程因環境不同——Pre-built Skills 不需要啟用、Custom Skills 上傳到 Claude.ai 或放進 Claude Code skills 資料夾。

# Claude.ai upload Custom Skill
1. Settings → Capabilities → Skills → Upload
2. Choose folder or .zip with SKILL.md inside
3. Skill appears in your library

# Claude Code filesystem Skills
~/.claude/skills/                 # Personal
└── my-legal-review/
    ├── SKILL.md
    └── references/

# Project-level
.claude/skills/                   # Per-project

4. Claude Skills 4 步驟使用內建 Skills

Verify Code Execution enabled

Settings > Capabilities 確認 Code execution and file creation 已開。Pre-built Skills（pptx xlsx docx pdf）需要 Code Execution 才能跑。

Ask Claude with task description

開新對話、明確描述需求例如「做一個再生能源 5 頁 PowerPoint」「分析這個 CSV 並產 Excel Dashboard」。Claude 自動匹配對的 Skill。

Wait for skill loading

Claude 偵測 Skill 後載入完整 Instructions、跑 Code Execution 產檔案。看到 Loading skill 訊息表示 Progressive Disclosure 第二層觸發。

Download generated file

Claude 完成後在對話下方產下載連結（pptx xlsx docx pdf）。點 Download 取檔。檔案儲存在 Anthropic 服務器 30 天 Cache。

5. 它能做哪些任務？

它涵蓋的任務類型廣泛。Document Generation、Code Review、Brand Voice Consistency、Compliance Check 都有專屬 Skill 對應。每個 Skill 用 SKILL.md 描述何時觸發、Instructions 怎麼處理、Output 格式。Progressive Disclosure 機制讓 50+ Skills 同時存在不會 Token 爆炸。

7. Progressive Disclosure 怎麼運作？

Progressive Disclosure 是 Skills 的核心設計、解決 Token 爆炸問題。三層載入——Metadata Only（啟動時只載入 name + description）、Skill Activation（匹配後載入完整 Instructions）、Reference Files（需要時動態載入子文件）。讓 Skill 數量幾乎沒有實際上限。

10. 使用 Claude Skills 有哪些限制？

它雖然強大實際使用仍有限制。第一是 Beta 階段不穩定——Skills API 仍在 Public Beta、版本可能更新、Backward Compatibility 不保證。Production 用要做好 Version Pinning。

第二是 Activation 不一定精準——Claude 自動匹配 Skill 偶爾會錯。description 寫法直接影響觸發精度、實務上需要幾次迭代測試。

第三是 Skill 維護成本——一旦 Skills 數量超過 20 個維護開始困難。每個 Skill 的 description 是否還準確、Instruction 是否還對應現況需要定期 Audit。

第四是 Open Standard 不等於完全 Portable——同 Skill 在 ChatGPT 跑 Anthropic 寫的版本行為可能不一致。Cross Platform 要 Test Each Platform。

第五是 Sensitive Data Skills——把公司內部 Best Practice 包成 Skill 上傳等於儲存在 Anthropic 服務器。Compliance 嚴格場景考慮 Workspace Skills 隔離或私有部署。

第六是 Always Test Skills Before Production——任何新 Skill 上線前要跑 5-10 個典型任務驗證 Output 品質。Skill 在 Edge Case 行為偶爾不可預測、Production 用之前要 Stress Test。

12. 常見問題 FAQ

Claude Skills 和 ChatGPT GPTs 有什麼差別？

Claude Skills 是 Open Standard 規格、SKILL.md 格式公開、能跨 ChatGPT Codex 等其他 AI 平台用。ChatGPT GPTs 是 OpenAI 生態獨家、要在 GPT Store 發布。實務上看你需要 Open vs Marketplace 哪個重要。

Claude Skills Free 帳號可以用嗎？

Pre-built Skills Free 也能用。Custom Skills 上傳功能 Pro 月費 20 美金以上才有。Claude Code 連 Free 都能用 Filesystem Skills（放在 ~/.claude/skills/）。

SKILL.md description 要寫多長？

控制在 30-100 字。包含三個元素——Skill 做什麼、何時用、輸出什麼。Anthropic 官方 17 個 Skills 的 description 是好範本可參考。

Claude Skills 會記住歷史互動嗎？

Skills 本身是無狀態（Stateless）——每次對話 Claude 重新載入 Skill Instructions。如果想要記住歷史互動、要搭配 Memory 或 Projects。

OpenAI 也採用 Skills 規格是真的嗎？

是。2025 年 12 月 Anthropic 把 Skills 規格開源成 Industry Standard。OpenAI Cursor Windsurf Gemini CLI 都加入支援。

Skill 觸發不準怎麼辦？

主要靠改善 description——具體列觸發場景、加常見任務 Keyword、Test 5-10 個典型 Prompt 看是否觸發。可參考 Anthropic 官方 17 Skills 的 description 寫法。

Workspace Skills 怎麼集中部署？

Team Enterprise 方案的 Admin 在 Organization Settings > Skills 上傳。Auto Update 機制讓 Skill 更新後所有員工立即用新版本。Free Pro Max 個人帳號沒這個功能。

Claude Skills 中文支援怎麼樣？

很好。SKILL.md 內可以全中文寫 Instructions、description 中英都能解析。中文使用者寫客製 Skill 完全可行、Output Format 中英都支援。
